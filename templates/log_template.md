# 🧠 TRAINING LOG SYSTEM

## RULES

- Always keep same structure
- Be brief but insightful
- Max 3 bullets in Analysis
- Always include Confidence
- Structure must reflect workout type
- "Main" is mandatory
- Warmup / Cooldown optional
- Recovery goes inside Main when applicable

---
